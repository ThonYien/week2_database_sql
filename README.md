## Description
This assignment demonstrates my understanding of SQL queries using MySQL Workbench. I practised retrieving, filtering, sorting, and limiting records from different database tables.

1. Retrieved payment information from the `payments` table.

4. Retrieved all records from the `offices` table.
5. Retrieved the five cheapest products from the `products` table.
